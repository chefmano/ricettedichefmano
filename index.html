Guida Hosting Gratuito e Privato

Come pubblicare questo sito solo per te senza spendere un euro

💡 Nota Importante: Questo sito salva tutte le ricette direttamente nel tuo browser (Local Storage). Nessuno oltre a te può vedere i tuoi dati.

1 Opzione 1: GitHub Pages (Gratuito al 100%)

  1. Crea un account gratuito su GitHub.com.
  2. Crea un nuovo "Repository" pubblico o privato e carica questo file chiamandolo index.html.
  3. Vai nelle impostazioni del repository (Settings -> Pages) e attiva GitHub Pages.
  4. In pochi secondi avrai un link del tipo: https://tuonome.github.io/ricettario.

2 Opzione 2: Netlify o Vercel (Trascina e Pubblica in 1 Click)

  1. Registrati gratis su Netlify.com o Vercel.com.
  2. Trascina semplicemente la cartella contenente questo file index.html nella loro dashboard.
  3. Otterrai subito un dominio gratuito personalizzato (es: il-mio-ricettario.netlify.app).
  4. Puoi persino impostare una password di protezione sul sito!

3 Come funziona l'Estrapolazione da Instagram / Facebook?

Incollando il link di un Reel o Post, il nostro sistema integrato di intelligenza artificiale analizza la struttura del post, riconosce ingredienti, tempistiche di cottura e dosaggi e li organizza automaticamente in schede pulite ed ordinate per la tua cucina.
